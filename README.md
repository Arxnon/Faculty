# Faculty — учёт сотрудников кафедры

Настольное приложение для учёта сотрудников, их публикаций и достижений.
Данные хранятся локально в базе SQLite, отчёты выгружаются в Excel.

## Возможности

- **Сотрудники**: ФИО, дата рождения, должность, учёная степень, звание; поиск по ФИО (в том числе по кириллице без учёта регистра).
- **Публикации**: название, издание, уровень, страницы, тип, дата, авторы (несколько, с сохранением порядка), прикреплённый файл.
- **Достижения**: мероприятие, достижение, город, организация, работа, дата, участники, прикреплённый файл.
- **История изменений**: журнал всех добавлений, правок и удалений.
- **Отчёты**: по сотрудникам (с выбором нужных), по году или произвольному интервалу дат, по уровню публикаций; выгрузка в `.xlsx`.

## Технологии

Python 3, PyQt5 (интерфейс из `main.ui`, стили в `style.qss`), SQLite, openpyxl, PyInstaller для сборки.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Тесты

Слой базы данных покрыт тестами на стандартном `unittest` (отдельные пакеты не нужны):

```bash
python -m unittest discover -s tests -v
```

## Где хранятся данные

База, вложения, резервные копии и журнал лежат в папке пользователя, а не рядом с программой:

| ОС | Папка |
|---|---|
| Windows | `%APPDATA%\Faculty` |
| macOS | `~/Library/Application Support/Faculty` |
| Linux | `~/.local/share/Faculty` |

Другую папку можно задать переменной окружения `FACULTY_DATA_DIR`.

При первом запуске данные из старого расположения (рядом с программой) копируются в эту папку автоматически.

## Защита данных

- внешние ключи включены, связи с публикациями и достижениями удаляются каскадно;
- каждое изменение выполняется транзакцией: при ошибке база остаётся в прежнем состоянии;
- версия схемы хранится в `PRAGMA user_version`, обновления выполняются миграциями;
- перед миграцией и раз в день делается резервная копия в `backups/` (хранятся последние 20);
- при запуске проверяется целостность базы.

## Сборка exe

```bat
build.bat
```

Готовая программа появится в `dist\Faculty`. База в сборку не входит — создаётся при первом запуске.

```
services/          история и работа с файлами
dialogs/           диалог выбора сотрудников
tests/             тесты базы данных
```
